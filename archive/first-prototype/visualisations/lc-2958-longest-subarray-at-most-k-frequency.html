LC 2958 · Length of Longest Subarray With at Most K Frequency

Sliding window (variable) + hash map O(n) time · O(n) space
Why this pattern?
  • Signals: "longest subarray" (contiguous, longest) plus a rule that every window must follow ("each value at most k times"). If a window breaks the rule, any bigger window that contains it breaks it too, so you can grow on the right and shrink on the left.
  • Brute force: try every start i, extend j to the right with a fresh count map until some value goes over k. O(n²) time, which is too slow for n = 10⁵.
  • Pattern: each index enters the window once (r) and leaves at most once (l), so the whole scan is O(n). The count map holds at most n keys: O(n) space.
  • Core idea: add nums[r]; only nums[r] can have gone over k, so move l right until count[nums[r]] ≤ k, then record the window length.
