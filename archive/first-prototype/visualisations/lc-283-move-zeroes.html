LC 283 · Move Zeroes

Two pointers · read / write O(n) time · O(1) extra space
Why this pattern?
  • Signals: "in-place" (no copy allowed), "keep the relative order", and "move some values to one end". Together they point to two pointers that move in the same direction: one reads, one writes.
  • Brute force: build a new array of the non-zeros and then the zeros. That is O(n) time but needs O(n) extra space, which breaks the in-place rule. Doing it in place by shifting everything left each time you meet a 0 costs O(n²).
  • Pattern: one pass, O(n) time, O(1) space. Each non-zero is swapped at most once.
  • Core idea: read finds each non-zero, write marks the next free slot for it, and a swap sends the non-zero left and pushes a zero right.
