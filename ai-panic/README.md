# ai-panic

Things the AI worried about while building this project, written down instead of being turned into extra code.

Rules:
- One worry per file: what could go wrong, how likely it is, what we would actually do.
- No ADR ever uses a file from here as a reason for a decision.
- If one of these really happens, move it to an ADR and add "(it happened)" to its title here.

Score so far: 0 came true.
