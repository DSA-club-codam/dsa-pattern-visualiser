Pointers, ranges and marks

Pointer names follow the pattern: left / right (towards each other, and window edges), slow / fast (same direction, linked lists), lo / mid / hi (binary search), p1 / p2 / write (merging two arrays: write blue, p1 and p2 orange). The trailing pointer is always blue, the leading one orange.
